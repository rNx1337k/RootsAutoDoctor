Gerado a partir de `rad/coverage.py` (não editar à mão). Níveis de prova: **Confirmado em hardware real**; **Validado com dados reais capturados**; **Testado com simulador**; **Implementado, não validado**; **Parcial**; **Bloqueado**; **Não implementado**.

Detectar o cabo no USB ≠ abrir a interface ≠ comunicar com uma centralina ≠ interpretar bem a resposta. Cada etapa tem o seu próprio nível.
